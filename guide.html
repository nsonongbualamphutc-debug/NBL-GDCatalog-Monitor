ภาษาไทยในไฟล์กลายเป็นตัวอักษรแปลก ๆ

ไฟล์ไม่ได้บันทึกเป็น UTF-8 ให้เปิดไฟล์ต้นฉบับใน Excel แล้ว Save As เป็น “CSV UTF-8 (Comma delimited)” ใหม่ จากนั้นแทนไฟล์ตามสถานีที่ 3

หน้าทรัพยากรขึ้น “ไม่สามารถแสดงผล (preview) ไฟล์ข้อมูลนี้ได้”
  1. แปลว่าไฟล์ยังไม่ถูกแปลงเป็น Data API (ยังไม่มีตาราง ไม่มีปุ่ม Data API)
  2. ถ้าปุ่มขวาบนเป็น “ไปสู่ทรัพยากร” แปลว่าใส่เป็นลิงก์ ให้กดจัดการแล้วอัปโหลดไฟล์ CSV แทนลิงก์
  3. ไฟล์ .xls/.xlsx/.pdf มักไม่ขึ้นตาราง ให้บันทึกเป็น CSV UTF-8 แล้วแทนไฟล์
  4. ตรวจว่าไฟล์เป็นตารางเดียว หัวตารางแถวเดียว ไม่มีเซลล์ว่างทั้งแถวคั่น
  5. ชื่อคอลัมน์ห้ามซ้ำกัน และห้ามว่าง
  6. แก้ไฟล์แล้วแทนไฟล์ใหม่ ระบบจะลองแปลงอีกครั้ง ถ้ายังไม่ได้ ติดต่อสำนักงานสถิติจังหวัด
Data Dictionary บอกว่าคอลัมน์ตัวเลขเป็น text

มีค่าที่ไม่ใช่ตัวเลขปนอยู่ เช่น “12,450” “-” “n/a” หรือมีหน่วยต่อท้าย ให้ลบลูกน้ำและหน่วยออก ช่องที่ไม่มีข้อมูลให้เว้นว่าง

มีแต่ไฟล์ PDF หรือรูปภาพ

PDF และรูปภาพไม่ผ่านเกณฑ์ Machine Readable ให้คัดลอกตัวเลขลง Excel ตามรูปแบบในสถานีที่ 1 แล้วอัปโหลดเป็น CSV เพิ่ม จะเก็บ PDF ไว้เป็นเอกสารประกอบด้วยก็ได้

อัปโหลดแล้วแต่หาชุดข้อมูลบนเว็บไม่เจอ

ชุดข้อมูลยังเป็น “ส่วนตัว” อยู่ กด จัดการ แล้วเปลี่ยน การเข้าถึง เป็น สาธารณะ แล้วกด ปรับปรุงชุดข้อมูล

ข้อมูลย้อนหลังบางปีหาไม่ได้จริง ๆ

ใส่ปีที่มี และระบุในช่อง รายละเอียด ว่าปีไหนไม่มีข้อมูลเพราะอะไร แล้วแจ้งสำนักงานสถิติจังหวัดเพื่อบันทึกเป็นกรณียกเว้น
